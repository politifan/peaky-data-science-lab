Peaky Minds Data Science / RouteLab. Дополнение 26.10.2026

Распакуйте весь архив. Рабочая папка student содержит requirements-lock.txt и блокнот 01-first-calculations.ipynb. В Windows откройте PowerShell из адресной строки этой папки:
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
.venv/Scripts/python.exe -m jupyter lab
В Linux/macOS: python3.12 -m venv .venv, затем .venv/bin/python. Далее python в примерах — полный путь выбранной venv.

Карта практик, не единый сценарий запуска подряд:
1. Python: 01-first-calculations.ipynb, Restart Kernel and Run All и собственные изменённые входы.
2. NumPy/математика: math_lab.py в соответствующем модуле.
3. pandas: измерения и таблицы из data; ноль, пропуск, полный дубль и конфликт различаются.
4. SQL: create_database.py создаёт outputs/orders.sqlite только если файла ещё нет. Для повтора --out outputs/orders-repeat.sqlite. Существующая учебная БД не затирается.
5. Вероятность/статистика: statistical_lab.py, гипотеза и предпосылки до вывода.
6. EDA: eda_lab.py, источники и единицы графиков.
7. ML: ml_lab.py — готовый учебный протокол, собственные кандидаты и выбор остаются вашей работой.
8. Реальные исторические примеры: real_data_lab.py, происхождение и лицензии в data/real-datasets-provenance.json сохраняются.
9. Временной ряд: time_lab.py — последовательный прогноз на один день с известным прошлым. Это не прогноз всех 60 дней из одной общей точки.
10. Повтор: reproduce.py outputs/ml сравнивает данные, split, test ID, вероятности и классы сохранённой late-модели. Joblib загружают от собственного обучения. Качество и отсутствие утечки проверяются отдельно по протоколу.
11. Battle: четыре намеренно неверных функции, open_checks.py ожидаемо падает до исправлений. Сохраняйте исходники и собственные наблюдения. state.py требует JSON-список в stdin и отдельный собственный путь состояния.
12. Проект: project/project_baseline.py даёт только baseline; расширьте до одного законченного RouteLab. Контракт артефактов и рубрика — в Stepik.

Исходники RouteLab синтетические. created_at — учебная календарная шкала без явного offset; не выдавайте её за независимо подтверждённые UTC моменты реального бизнеса. distance/weight/hour/city/weather считаются доступными в момент решения. duration, late, actual_receipt_at и post_event_cost не становятся допустимыми признаками late-классификации. Для прогноза duration отдельная цель и протокол.

Примеры записывают результаты в свои фиксированные outputs. Свой проект держите в отдельной новой папке и сохраняйте прошлые результаты перед повтором. Для БД действует отказ на существующую цель. DOCX редакции 2 сохранены для чтения; текущие уточнения находятся здесь и в Stepik. Отчёт может быть TXT/Markdown/DOCX. Нет подключённого External Grader и обещанной постоянной персональной проверки; краткие Stepik алгоритмы не равны независимой аттестации ML-проекта.

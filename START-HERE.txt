Распакуйте всё в новую папку. Рабочая папка student. Первый результат — короткая функция обработки измерений в Stepik, затем собственный notebook. В первом уроке не запускайте весь ML-проект.
Python 3.12, PowerShell из student:
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-lock.txt
.venv/Scripts/python.exe -m jupyter lab
Linux/macOS: python3.12 и .venv/bin/python; активация необязательна, ExecutionPolicy не меняют. Ниже python означает этот путь своей среды.

01-first-calculations.ipynb содержит только Python: имена/числа, None, условие, цикл, функция, словарь и проверка id. Контракт первой суммы: ноль сохраняется, None и отрицательные значения идут в карантин. Для [0,None,5,-2] валидны [0,5], сумма 5. Boolean отсутствует во входе этой задачи. Restart Kernel and Run All подтверждает чистое выполнение; измените собственный вход.
02-numpy.ipynb, 03-pandas.ipynb и 04-sql.ipynb относятся к следующим модулям. math_lab.py, statistical_lab.py, eda_lab.py, time_lab.py запускают после соответствующего объяснения. create_database.py отказывается перезаписывать существующую цель: для повтора используйте --out outputs/orders-repeat.sqlite. Не удаляйте данные ради зелёного результата.

ml_lab.py — разобранный пример с заранее выбранным линейным семейством. Для собственного выбора скопируйте project/experiment-plan.example.json в project/my-plan.json и до holdout запишите свою гипотезу, признаки, кандидатов и пороги. Сравните минимум baseline и содержательный кандидат; попробуйте свою обоснованную пару признаков/глубину/C.
python own_experiment.py project/my-plan.json outputs/my-attempt-01
python check_experiment.py outputs/my-attempt-01
Существующая папка попытки не перезаписывается. Разбиение — train первые 800, validation следующие 200, test последние 200 по created_at/order_id. Это будущий период прежнего синтетического процесса, не доказательство переноса на новых клиентов. Подготовка fit только на train. Кандидат и порог выбираются на validation по 2*FP+20*FN, затем один test. На диске сохраняются план/hash, split, validation, metadata, predictions, model и metrics. Нулевое улучшение допустимо, если вывод честен.
Для отрицательного контроля добавьте actual_receipt_at в копию плана: запуск обязан отклонить утечку. Изменённые после обучения план/split/вероятности checker должен отвергнуть. Для нового исследования используйте новый план и новую папку, не подбирайте решение по финальному test.

distance/weight/hour/city/weather доступны при решении только по объявленному синтетическому контракту набора. duration, late, actual_receipt_at и post_event_cost недопустимы как признаки late. Для реального источника нужна таблица происхождения и первичные моменты доступности; запись availability=at_decision сама этого не подтверждает. created_at — учебная шкала без явного UTC offset.
reproduce.py воспроизводит сохранённые прогнозы и классы. check_experiment.py дополнительно сверяет план/hash, заданный временной split и выбор по validation. Они не доказывают отсутствие преждевременного просмотра test и не заменяют разбор доступности данных. Загружайте joblib только собственного обучения.

Один самостоятельный RouteLab обязателен. В отчёте: вопрос, baseline, протокол, выбор, test, один сегмент ошибок с размером группы, чистый повтор, ограничения. Четыре battle-функции намеренно неверны, open_checks.py до исправлений ожидаемо падает. Реальные исторические учебные наборы сохраняют data/real-datasets-provenance.json.
